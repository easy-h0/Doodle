# Doodle.

대화로 감정을 발견하고, 낙서로 남기는 AI 기록 서비스

## 실행 방법

```bash
npm install
npm run dev
```

## 주요 기능

- 캔버스 기반 자유 낙서 (브러시 크기/색상/지우개)
- AI 실시간 코멘트 (그리기/지우기 상황별 멘트)
- AI 대화 (실시간 바 클릭으로 채팅)
- Undo/Redo, 캔버스 초기화
- 낙서 완료 시 결과 카드 (TODAY'S DOODLE)
- 카드 이미지 PNG 다운로드

## 기술 스택

React + TypeScript + Vite + Tailwind CSS
